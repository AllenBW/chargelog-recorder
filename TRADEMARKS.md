# Trademark policy

BluffWorks LLC uses "ChargeLog" and the ChargeLog logo to identify this project and the ChargeLog
Android app. We claim them as common-law marks arising from that use; **no registration has
issued, and a clearance search and application are still to come.** This document states our
position today rather than asserting a right that has been examined and granted.

What is settled either way is the licensing boundary: **the GPL-3.0-only license on this
repository's code grants no rights in the name or the logo.** Copyright and trademark are
separate, and open-sourcing the code does not open-source the name. That is true of a common-law
mark exactly as it is of a registered one.

The logo artwork is not in this repository — it belongs to the closed app — so there is nothing
here to copy. It is protected by copyright independently of anything on this page.

## What's fine

Referring to this project by name in ordinary, factual ways: "built on the ChargeLog recorder,"
"a fork of ChargeLog's recording engine," a link back to this repository. That's referential use,
not trademark use, and needs no permission.

## What's not

- Naming a fork, derivative, or unrelated app "ChargeLog" or anything confusingly similar.
- Using the ChargeLog logo or wordmark, or a close imitation of either, as your own app's icon or
  branding.
- Any use that implies your project is the official ChargeLog app, or is endorsed by or
  affiliated with it, when it isn't.

## Ask first

If you're building something on this code and want to use the name or the logo beyond the
referential use described above, ask before you ship: open an issue at
<https://github.com/AllenBW/chargelog-recorder/issues>. The same address reaches us for a
trademark question, a commercial-licensing question, or a disagreement with anything on this
page.
